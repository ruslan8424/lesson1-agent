# Project Agent Rules

- Do not modify files unless the user explicitly asks you to.
- Before modifying any file:
  1. Explain the proposed changes.
  2. Stop and wait for explicit user approval.
  3. Do not edit any file until the user approves.
- Prefer the smallest possible fix.
- Do not change unrelated files.
- After implementation, verify the changes.
- If verification reveals that another file change is needed, stop and ask for approval before making that change.
- Use npm.cmd instead of npm in PowerShell on this machine.
- Do not run destructive Docker or Git commands without explicit approval.
